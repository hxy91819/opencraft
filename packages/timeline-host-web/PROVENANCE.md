# Provenance

This package is the Web/Electron host adapter for the renderer-neutral
`@opencraft/timeline-virtualizer` model.

Behavior was recovered from Codex r1501, primarily:

- `lazy/app-initial/thread-scroll-layout-xQ2_L08y.js`
- `shared/preserve-timeline-scroll-position-on-reflow-09693.tsx`
- `shared/shared-bindings-09694.ts`
- `modules/ui-islands-v11/use-toggle-diff-panel-subscription.js`

The `VisualViewport` software-keyboard adapter is a browser capability added
for OpenCraft Web/iPad. It is intentionally not attributed to the Electron source.
