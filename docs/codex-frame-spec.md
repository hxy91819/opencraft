# Codex frame specification

The OpenCraft frame follows the latest fixed-point Codex recovery, not an earlier
screenshot approximation. Its source baseline is:

`reference://codex/.runtime/partition-r822-shared-owner-semantic-locals`

The downstream acceptance lineage is r823 (audit), r824 (build), r825
(browser differential), and r826 (hydration). Physical CSS is the r258 asset;
its original SHA lineage is unchanged in the later semantic partitions.

left navigation, one elevated main content surface, an optional right child
panel, centered thread content, top fade, and a bottom composer. The light
theme is the default and is generated by the recovered dynamic contrast
algorithm rather than a hand-authored color approximation.
